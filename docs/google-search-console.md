# Google Search Console

Google Search Console integration is optional in this blueprint.

Recommended future modules:

- Query performance ingestion
- High-impression low-CTR detection
- Striking-distance keyword detection
- Crawled-not-indexed monitoring
- Discovered-not-indexed monitoring
- Indexing recovery tracker

Recommended human process:

1. Deploy a technical fix.
2. Inspect priority URL in Search Console.
3. Run Live URL Test.
4. Confirm user-declared canonical.
5. Request indexing.
6. Monitor indexing report.

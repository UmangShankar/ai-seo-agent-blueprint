# Safety Principles

## Allowed automatically

- Crawl pages
- Read sitemaps
- Inspect metadata
- Generate diagnostics
- Create approval packs

## Requires human approval

- Content edits
- Metadata rewrites
- Canonical changes
- Internal linking changes
- New pages
- Production deployment

## Not allowed

- Keyword stuffing
- Doorway pages
- Hidden text
- Auto-generated spam pages
- Auto-publishing AI content
- Bypassing pull request review

# Agent Model

## Site Discovery Agent

Reads sitemap.xml and produces a URL inventory.

## Crawler Agent

Fetches each page and extracts title, description, canonical, robots, H1s, and links.

## Canonical Audit Agent

Flags missing, duplicate, or incorrect canonical signals.

## Metadata Audit Agent

Flags missing or weak titles, descriptions, and H1s.

## Link Audit Agent

Flags pages with weak internal linking.

## Approval Pack Agent

Turns findings into checkbox-style actions for human review.

## QA Agent

Runs audits again after implementation.

# Generated Report Files

After running:

```bash
npm run seo:report
npm run seo:pr-pack
```

Expect these local files:

- `seo-reports/canonical-audit.json`
- `seo-reports/canonical-audit.md`
- `seo-reports/metadata-audit.json`
- `seo-reports/metadata-audit.md`
- `seo-reports/link-audit.json`
- `seo-reports/link-audit.md`
- `seo-reports/approval-pack.md`

These files are ignored by git because they are generated for the configured site. Commit source, docs, tests, and workflows instead.
